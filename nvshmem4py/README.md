# nvshmem4py for MTSHMEM

Python bindings for MTSHMEM's NVSHMEM-compatible host APIs.

This tree is based on the upstream MTSHMEM 3.7.0 `nvshmem4py` package and keeps the
upstream `nvshmem` Python module name for API compatibility. The MTSHMEM build uses
MUSA headers and a small Python compatibility layer for the initial core API surface.
